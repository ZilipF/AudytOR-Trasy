# AudytOR-Trasy
Planowanie tras audytowych stacji paliw.

Projekt został rozdzielony z jednego pliku HTML na trzy główne pliki:

- `index.html` — struktura aplikacji i linki do bibliotek z CDN
- `styles.css` — cały wygląd aplikacji
- `script.js` — cała logika aplikacji

## Jak edytować w vscode.dev

1. Pobierz i rozpakuj `AudytOR_Trasy_vscode_project.zip`.
2. Wejdź na `vscode.dev`.
3. Wybierz `Open Folder` i wskaż rozpakowany folder projektu.
4. Edytuj pliki `index.html`, `styles.css`, `script.js`.
5. Do testowania otwieraj lokalnie `index.html` w przeglądarce.

## Ważne

Aplikacja nadal korzysta z bibliotek zewnętrznych przez CDN:

- Leaflet CSS/JS
- XLSX
- Google Fonts

Dlatego do pełnego działania map, importu Excel i geokodowania potrzebny jest dostęp do internetu.
